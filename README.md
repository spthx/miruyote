# ミルヨテ

自分の視聴環境に合わせて、今期アニメの次回予定を確認する個人用MVPです。季節はアクセス日から自動判定します。

## できること

- AniListから今期作品・継続放送中の作品と次回予定を取得し、明らかな再放送を除外
- 「観たい」作品を端末内に保存し、次回から一覧の先頭に表示
- 加入サービス・視聴局を端末内に保存
- 公式情報で確認した時刻を自分用に補正
- 10分前アラーム付きICSカレンダーを書き出し
- PWAとしてホーム画面から利用
- お気に入り・視聴環境・時刻補正をJSONでバックアップ／復元

ユーザー設定はLocalStorageにのみ保存され、GitHubへ送信されません。同じiPhone・同じブラウザでは次回も残りますが、Safariの履歴／Webサイトデータ消去、端末の初期化、別ブラウザへの変更では失われる場合があります。設定画面の「バックアップを作る」でJSONを保存しておくと復元できます。

「観たい」の優先表示は現在のシーズン内で行います。次のシーズンでは作品IDが変わるため、旧シーズンのお気に入りは保存されたままでも新シーズン一覧には現れません。表示時刻は参考情報を含むため、変更・延期は公式情報も確認してください。

## カレンダー購読（重複しにくい運用）

「観たい」作品ごとに毎回ICSをダウンロード＆インポートすると、同じ予定が重複登録されやすくなります。これを避けるため、固定ファイル名で公開し、カレンダー側から「URLで購読」してもらう方式を用意しています。

1. 設定画面の「calendar.ics を書き出す」でファイルをダウンロードする
2. ダウンロードした `calendar.ics` をリポジトリ直下（`index.html` と同じ階層）に置き、`git add calendar.ics && git commit -m "update calendar" && git push` する
3. 設定画面の「購読URLをコピー」でURLを取得し、iPhoneなら「設定 → カレンダー → アカウントを追加 → サブスクライブ済みカレンダーを追加」、Googleカレンダーなら「他のカレンダーを追加 → URLで追加」に貼り付ける
4. 「観たい」作品や時刻補正を変更したら、1〜2を繰り返して `calendar.ics` を最新化する

カレンダーアプリは数時間おきにこのURLを再取得し、中身をまるごと置き換えるため、都度ダウンロード＆インポートする方式のような重複は起きません。ただし再取得の頻度はカレンダーアプリ側の仕様に依存し、即時反映は保証されません。

## iPhoneでの登録

設定画面または今日画面の「カレンダーへ追加」を押すと、「観たい」にした作品の次回予定が1つのICSファイルにまとまり、iPhoneのカレンダー取込画面を直接開きます。初期版と同じ即時導線です。

直接開かなかった場合だけ「開けないとき」を押し、次の予備手順を使います。

1. 「共有画面を開く（メールを選ぶ）」を押す
2. Apple純正の「メール」を選び、ICSを添付したまま自分宛てに送信する
3. 受信したメールのICSを開き、「すべて追加」を押す

AppleはiPhoneへのICS読み込み方法としてメール経由も案内しています。「ICSだけ保存」は保管・PC転送用の予備手段です。長い日本語タイトルを含む予定もiOSが正しく読めるよう、ICSは仕様に沿って行を折り返して出力します。
