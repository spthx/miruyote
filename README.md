# ミルヨテ

自分の視聴環境に合わせて、2026年夏アニメの次回予定を確認する個人用MVPです。

## できること

- AniListから今期作品と次回予定を取得
- 「観たい」作品を端末内に保存
- 加入サービス・視聴局を端末内に保存
- 公式情報で確認した時刻を自分用に補正
- 10分前アラーム付きICSカレンダーを書き出し
- PWAとしてホーム画面から利用

ユーザー設定はLocalStorageにのみ保存され、GitHubへ送信されません。表示時刻は参考情報を含むため、変更・延期は公式情報も確認してください。

## カレンダー購読（重複しにくい運用）

「観たい」作品ごとに毎回ICSをダウンロード＆インポートすると、同じ予定が重複登録されやすくなります。これを避けるため、固定ファイル名で公開し、カレンダー側から「URLで購読」してもらう方式を用意しています。

1. 設定画面の「calendar.ics を書き出す」でファイルをダウンロードする
2. ダウンロードした `calendar.ics` をリポジトリ直下（`index.html` と同じ階層）に置き、`git add calendar.ics && git commit -m "update calendar" && git push` する
3. 設定画面の「購読URLをコピー」でURLを取得し、iPhoneなら「設定 → カレンダー → アカウントを追加 → サブスクライブ済みカレンダーを追加」、Googleカレンダーなら「他のカレンダーを追加 → URLで追加」に貼り付ける
4. 「観たい」作品や時刻補正を変更したら、1〜2を繰り返して `calendar.ics` を最新化する

カレンダーアプリは数時間おきにこのURLを再取得し、中身をまるごと置き換えるため、都度ダウンロード＆インポートする方式のような重複は起きません。ただし再取得の頻度はカレンダーアプリ側の仕様に依存し、即時反映は保証されません。
